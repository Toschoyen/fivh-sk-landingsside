# FIVH SK – landingsside (wireframe v2)

Innholdsutkast / wireframe til gjennomgang, **ikke endelig design**.

- Eneste innhold i dette repoet er `index.html` (selvstendig, ingen eksterne ressurser).
- Inneholder bevisst **ingen** konfidensielle dokumenter, budsjett eller andre klienter.
- Oransje prikker = mine kommentarer. Klikk en prikk for å se hva seksjonen er og hvorfor den er bygd slik. Knappen nede til høyre skjuler eller viser alle.

Kilde og full prosjektkontekst ligger privat i Fjordigitals interne lager (ikke her).

## fjordigital-varianter/

Egen, uavhengig side: designvarianter for Fjordigitals egen forside (fjordigital.no), til intern gjennomgang. Har ingenting med FIVH-landingssiden å gjøre. Kundenavnene der er de samme som står på Fjordigitals offentlige forside.
